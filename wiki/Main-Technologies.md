# Main Technologies

The Nexa ecosystem integrates several modern tech stacks to deliver premium performance:

## Frontend (WebApp & Website)
- **HTML5 & CSS3**: Structured markup and vanilla styling.
- **Angular 21 (v21.2.17)**: Central client framework for modular, reactive SPA.
- **TypeScript 5.9 (v5.9.3)**: Strongly typed programming language for client logic.
- **Angular Material 21 (v21.2.14)**: Component library for dashboard controls.
- **PrimeIcons 7**: Vector icon library for navigation and actions.
- **Angular Signals**: Reactivity model and state management (Stores).
- **Angular HttpClient**: RESTful API consumer.
- **Custom I18n**: Signals-based custom internationalization (`I18nService` and `t` pipe).

## Backend (Platform API)
- **Java 21**: Core programming language and runtime.
- **Spring Boot 3.3.6**: Application framework for RESTful services.
- **Spring Data JPA & Hibernate 6.5.3**: Object-Relational Mapper (ORM) and persistence management.
- **Spring Security & JJWT 0.12.6**: Security framework with JSON Web Token validation.
- **PostgreSQL 16**: Relational database persistence (deployed on Render).
- **H2 Database 2.2.224**: In-memory database for local development and testing.
- **Springdoc OpenAPI 2.6.0**: Interactive Swagger API documentation.
- **Maven**: Build automation and dependency management tool.

## Infrastructure & Hosting
- **Render**: Main cloud platform hosting the frontend WebApp and the backend Platform REST API.
- **GitHub Pages**: Host for the public Landing Website.
- **Docker**: Containerization for local deployment.
- **Jira Software**: Agility board tracking and release planning.
